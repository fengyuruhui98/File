# LeetCode-3117.划分数组得到最小的值之和
2024.08.16  
难度：困难    
给你两个数组 $nums$ 和 $andValues$，长度分别为 n 和 m。
数组的**值**等于该数组的 **最后一个** 元素。
你需要将nums划分为m个不相交的连续子数组，对于第 ith 个子数组 $[l_i, r_i]$，子数组元素的按位 AND 运算结果等于 andValues[i]，换句话说，对所有的 $1 <= i <= m，nums[l_i] \& nums[l_i + 1] \& ... \& nums[r_i] == andValues[i]$ ，其中 & 表示按位 AND 运算符。
返回将 nums 划分为 m 个子数组所能得到的可能的 最小 子数组 值 之和。如果无法完成这样的划分，则返回 -1 。

>示例一
输入： nums = [1,4,3,3,2], andValues = [0,3,3,2]
输出： 12
解释：
唯一可能的划分方法为：
[1,4] 因为 1 & 4 == 0
[3] 因为单元素子数组的按位 AND 结果就是该元素本身
[3] 因为单元素子数组的按位 AND 结果就是该元素本身
[2] 因为单元素子数组的按位 AND 结果就是该元素本身
这些子数组的值之和为 4 + 3 + 3 + 2 = 12

>示例 2：
输入： nums = [2,3,5,7,7,7,5], andValues = [0,7,5]
输出： 17
解释：
划分 nums 的三种方式为：
\[[2,3,5],[7,7,7],[5]] 其中子数组的值之和为 5 + 7 + 5 = 17
\[[2,3,5,7],[7,7],[5]] 其中子数组的值之和为 7 + 7 + 5 = 19
\[[2,3,5,7,7],[7],[5]] 其中子数组的值之和为 7 + 7 + 5 = 19
子数组值之和的最小可能值为 17

>示例 3：
输入： nums = [1,2,3,4], andValues = [2]
输出： -1
解释：
整个数组 nums 的按位 AND 结果为 0。由于无法将 nums 划分为单个子数组使得元素的按位 AND 结果为 2，因此返回 -1。

>提示：  
1 <= n == nums.length <= 104
1 <= m == andValues.length <= min(n, 10)
1 <= nums[i] < 105
0 <= andValues[j] < 105

# 解
## 思路
朴素的动态规划递推式并不难想到
***$dp[n][m]=nums[n]+min_{And_{i≤j≤n​}nums[j]=andValues[m]}dp[i−1][m−1]$***

初始条件为
$dp[−1][−1]=0$
$dp[−1][m]=+∞(m≥0)$
$dp[n][−1]=+∞(n≥0)$

重点在于如何优化第二项，让它不需要穷举所有的$i$，达到对每个$n$和$m$均摊$O(1)$的复杂度。这里用到几条简单的性质：

### 定义 1: **$And(u,v):=And_{u≤i≤v}nums[i]$**
也就是将$nums$中下标为$[u, v]$（闭区间），或者说$nums[u:v+1]$中元素的$and$的结果记为$And(u,v)$，方便后面描述。使用这个记号可以改写前面的递推式：
$dp[n][m]=nums[n]+min_{And(i,n)=andValues[m]}dp[i−1][m−1]$
### 引理 1: $And(u,v)$关于$u$单调不减，关于$v$单调不增.
根据比特与的定义很容易得到，因为两个数与之后的结果不超过两者中任意一个，因此增加与的元素只会让值变小或不变，而不会变大

### 定义 2: **$Left(i,t):=\{j∣And(j,i)=t\}$**
也就是对于下标$i$和目标值$t$，定义$Left(i,t)$是所有使得下标$[j,i]$之间元素$and$的结果等于$t$的$j$的集合

### 引理 2: $Left(i,t)$是空集，或者一个连续区间
根据**定义2**和**引理1**，如果$Left(i,t)$中包含了两个不同的整数，那么根据单调性，这两个整数之间的下标对应的$And(j,i)$也一定等于$t$，因此它们也在集合中

### 定理 1: $Left(i,t)$是空集，或者包含 $Left(i−1,t)$
如果$nums[i]\&t=t$，则根据定义很容易知道$Left(i−1,t)$中包含的所有区间，右边再增加$nums[i]$，与的结果仍然是$t$，因而按照定义它们是$Left(i,t)$的一部分。如果$nums[i]\&t\not=t$，说明它缺少需要的$bit$，很容易知道$Left(i,t)$必须是空集

### 定理 2: 如果 $Left(i,t)$和 $Left(i−1,t)$都非空，则两个集合的最小值相等.
根据**定理1**已经知道$Left(i−1,t)$的最小值一定在$Left(i,t)$中，如果$Left(i,t)$的最小值更小，考虑两个集合的最小值各自对应的区间，然后将较大的部分拆分成三部分即可证明，详细证明略。

### 定理 3 如果 $Left(i,t)$和 $Left(i−1,t)$都非空，当且仅当$And(maxLeft(i−1,t)+1,i)=t$时两者不相等
根据**引理2**，非空时永远是个区间，而且根据**定理2**左端点一定是相等的，只能是右端点不同；再根据**定理1**，只能是$Left(i,t)$的区间右端点更大，那么只需要考虑$Left(i−1,t)$的右端点 $+ 1$的值是否在$Left(i,t)$中即可。

## 解题过程
根据前面的证明，我们可以得到以下结论：

1. 保持$m$不变，$n$逐渐增加时，递推式中求最小值的范围只会不断增加或者变为空，不会减少元素，因此可以通过记录上一次的最小值，再跟新追加的范围取最小，来降低复杂度
2. $n$变大时可以分为两种情况，如果新增加的值缺少$andValues[m]$中需要的某些$bit$，则范围变为空，并且之后的位置的$Left(i,t)$中也一定不包含当前下标；否则从$maxLeft(n−1,t)+1$开始依次判断是否变成了可用的左端点即可。
3. 为了方便起见，$Left(n,t)$为空的时候也用区间形式表示，如果当前值不缺少$bit$但没有可用的左端点，区间表示为$[L,L−1]$，其中$L$是上一个缺少$bit$的下标 $+ 1$，或者$0$。如果当前值缺少$bit$，区间表示为$[n+1,n]$。它保证了$n$继续增加的时候，如果不缺少$bit$，左端点始终是不变的。

问题回归到如何快速计算一个区间的$and$的结果，比较直接的办法是使用$Sparse Table$，经过$O(nlogn)$复杂度的预处理之后用$O(1)$复杂度查询任意区间的$and$的结果，这样就可以直接实现上面的算法。

更复杂一点的方法可以无需预处理，要点在于合理延后和缓存已经进行的计算，避免重复计算。具体来说，在递推过程中，将$[L,n+1]$之间的范围进一步细分成连续不重叠的三部分，其中$L$表示上一个缺少$bit$的下标 $+ 1$，或者$0$：

$Left(n,t)$对应的区间，这部分区间在递推过程中无需进一步处理了
已处理区间，它在三段区间中间，代表之前已经计算过一部分$and$结果的下标，具体定义后面描述
未处理区间，它在最右边，新加入的元素首先进入这个区间进行累积，整个区间中所有元素$and$的结果是不断更新的。它的左端点记为$left$
新加入下标为$i$的元素的时候，首先更新未处理区间的$and$的结果，有三种可能的结果：

### 1. 缺少了需要的$bit$
所有累积内容重置，相当于从头重新开始，$left = i + 1$
### 2. 未处理区间$and$的结果恰好是需要的结果
根据前面的定理，这时候我们主要需要知道的是可用的左端点的最大值，我们从右向左依次计算$And(j,i)$，每次只加入一个元素，直到结果为需要结果位置。以这一点为分界更新$Left(i,t)$，未处理区间在这一点以及左侧的和上一次的已处理区间一起加入$Left(i,t)$，更新最小值；这一点右侧的（不包括这一点）为新的已处理区间。我们将过程中计算出的$And(j,i)$放入一个栈缓存起来。注意到未处理区间被完全分成了$Left(i,t)$和已处理区间，新的未处理区间是空的，将累积值清空，$left = i + 1$
### 3. 未处理区间and的结果不是需要的结果
这时已处理区间可能有已经加入$Left(i,t)$的点，从左到右处理，由于进栈是从右到左，从栈顶出栈正好就是从左到右。栈中的点$j$到$i$的$And(j,i)$，可以用栈中缓存的结果与当前未处理区间累积的$and4结果再与一次得到。如果结果是需要的结果，出栈并更新最小值

## 复杂度
每个元素在每一轮最多进出未处理区间一次，进出已处理区间一次，进出$Left(i,t)4，因此每轮的复杂度都是$O(n)$，$m$轮整体复杂度不超过$O(nm)$。

时间复杂度: $O(nm)$
空间复杂度: $O(n)$


```python
class Solution:
    def minimumValueSum(self, nums: List[int], andValues: List[int]) -> int:
        N = len(nums)
        INF = float('inf')
        # 滚动数组，偏移一个位置
        dp = [INF] * (N + 1)
        dp[0] = 0
        for j, av in enumerate(andValues):
            dp2 = [INF] * (N + 1)
            # 当前累积段的左端点
            left = 0
            # 所有可用的左端点中dp的最小值
            current_min = INF
            # 当前累积段的与的结果
            current_and = -1
            # 已经处理过的放在栈里避免重新处理，保证复杂度
            # 栈里下标为j的位置，对应的是left - j - 1
            stack = []
            for i, v in enumerate(nums):
                next_and = (current_and & v)
                if next_and == av:
                    # 当前累积段符合目标，可用的左端点的最大值在这个范围内
                    # 从右向左遍历找
                    # 栈里之前的内容可以清空了，但长度需要保留，后面计算最小值要用
                    stack_len = len(stack)
                    del stack[:]
                    and2 = -1
                    for l2 in range(i, left - 1, -1):
                        next_and2 = and2 & nums[l2]
                        if next_and2 == av:
                            break
                        else:
                            # 将来可能会进入可用的左端点范围，把这个值保留下来放在栈里
                            stack.append(next_and2)
                            and2 = next_and2
                    #print(f'j={j}, right={i}, left=+[{left}, {l2}], stack={stack}')
                    # 更新最小值
                    for k in range(left - stack_len, l2 + 1):
                        current_min = min(current_min, dp[k])
                    # 已经处理过放在栈里的也不再累积
                    left = i + 1
                    next_and = -1
                elif (next_and & av) != av:
                    # 缺少了需要的bit，当前没有可用的左端点，累积内容都需要清空
                    next_and = -1
                    left = i + 1
                    current_min = INF
                    del stack[:]
                else:
                    # 处理过的段从左到右判断是否进入可用左端点范围
                    while stack and (stack[-1] & next_and) == av:
                        current_min = min(current_min, dp[left - len(stack)])
                        stack.pop()
                current_and = next_and
                dp2[i + 1] = current_min + v
            #print(dp2)
            dp = dp2
        if dp[-1] == INF:
            return -1
        else:
            return dp[-1]
```
